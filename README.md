[grblHAL](https://github.com/grblHAL) driver for Gigadevice GD32F30x based on [STM32F3xx](https://github.com/grblHAL/STM32F3xx) grblHAL driver

Build with VS Code & PlatformIO

grblHAL драйвер для плат контроллеров на базе GD32F30x.
Сборка производится средствами VS Code с установленным PlatformIO.
Прошивка с помощью FlyMCU или ST-Link.
